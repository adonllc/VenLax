Design — Section 4: Web App (apps/web)

Next.js 15 App Router · RSC for public/SEO · React Query for authenticated interactive surfaces

Public Routes — RSC (SSR/SSG)
/
Landing page → redirects to /home if authed
/markets
SSG market browser, category tabs, search
/markets/[id]
SSR · OG meta · ProbabilityBar
ForecastEntryWidget = client component island
/reviews/[productId]
SSR product review page (SEO indexed)
Auth Routes (unauthenticated only)
/auth/login
Email/password · redirects to /home on success
/auth/register
Name · email · password · 18+ age gate
Shared Layout (all authed pages)
TopBar: logo · search · ⚡ FP balance · notification bell · avatar
ThemeProvider (dark/light toggle)
QueryClientProvider wraps all client components
AuthGuard redirects → /auth/login if token missing
Authenticated App Routes — React Query
/home Activity feed, missions, streak banner, AI signals
/forecast Open positions, forecast history
/reviews Browse + submit reviews
/rewards Wallet summary + reward catalog
/rewards/redeem/[id] Redemption confirmation + KYC gate
/leaderboard Accuracy leaderboard, filter by category
/profile Own profile: badges, XP, history
/profile/[userId] Public profile + follow button
/settings Account, theme, notifications
/settings/subscription Tier upgrade via Stripe Checkout
Market Detail Page — RSC + Client Island
Server: title, description, resolution criteria, current probability (initial snapshot), OG meta tags

Client island: ForecastEntryWidget subscribes to WebSocket — live probability updates, YES/NO buttons, FP slider, React Query mutation for forecast entry

InsightCard (Pro+ only) — React Query fetch, disclaimer modal on first view
