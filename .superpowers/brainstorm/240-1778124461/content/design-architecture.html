Design — Section 1: Architecture Overview

How the four deliverables fit together

① packages/ui — built first
Shared component library. Web exports React + Tailwind components. Mobile exports React Native StyleSheet variants under the same import paths.
MarketCard · ProbabilityBar · FPBadge · StreakBanner · Button · Input · InsightCard · ReviewCard · RewardCard · BadgeDisplay · LeaderboardRow · Avatar · BottomSheet
② apps/admin — built second
Internal Next.js 15 panel. Separate admin_users table + JWT secret + TOTP 2FA. Sidebar layout, no bottom tabs.
Login · 2FA · Dashboard · Markets · Users · FP Adjustments · Review Moderation · Analytics
③ apps/web — built third
Next.js 15 App Router. RSC for public/SEO pages (market detail, product reviews). React Query for all authenticated interactive surfaces.
Home · Markets · Forecast entry · Reviews · Rewards · Profile · Leaderboard · Subscriptions · Auth
④ apps/mobile — built last
Expo Router v3. 5-tab bottom bar. Push notification deep links. Native bottom sheets. React Query for server state (same hooks as web).
Home · Forecast · Reviews · Rewards · Profile + all detail screens
