Phase 3 has three independent apps — which do we build first?

Each app is a full implementation effort. Pick the one that delivers the most value fastest.

A

Web App (Next.js 15 · apps/web)

Public-facing product — Home feed, Market browser, Forecast entry, Reviews, Rewards wallet, Profile. SSR for SEO + OG cards. WebSocket live prices. Keyboard shortcuts.

User-facing SEO / OG sharing Most complex
B

Admin Panel (Next.js 15 · apps/admin)

Internal tool — Market management, User management, FP adjustments (supervisor approval), Review moderation queue, Basic analytics dashboard. 2FA gated.

Operational necessity Fastest to build Unlocks product use
C

Mobile App (Expo 51 · React Native · apps/mobile)

iOS + Android — Tab bar: Home | Forecast | Reviews | Rewards | Profile. Push notification deep links. Native animations. Bottom sheets. Streak multiplier UI.

Primary distribution App Store / Play Store Longest build time
D

All three — parallel specs, sequential build

Design all three apps together now, then build in recommended order: Admin → Web → Mobile. One comprehensive spec, three implementation plans.

Full picture upfront Consistent design Longer brainstorm
